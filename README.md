 ReviewAI — AI-Powered Code Reviewer for GitHub

ReviewAI is a full-stack AI-powered code review platform that analyzes code using LLMs and provides real-time feedback, suggestions, and improvements for better code quality and performance.


 Features

 AI-based code analysis using OpenAI / Gemini APIs  
   Real-time code feedback and suggestions  
   Detects bugs, inefficiencies, and bad practices  
   Clean UI with Monaco Editor for code editing  
   Supports multiple programming languages  
   Structured feedback (errors, improvements, optimizations)  
  REST API-based architecture

# How It Works

1. User pastes or writes code in the editor  
2. Code is sent to backend API  
3. AI model analyzes code using prompt engineering  
4. Structured feedback is returned:
   - Errors  
   - Improvements  
   - Optimization suggestions  
5. Results displayed in UI in real-time
